# Omoluabi Chess 3D

## Project at a glance

**Category:** Browser-based 3D chess prototype  
**Purpose:** Render and explore a three-dimensional chessboard with Three.js  
**Intended readers:** Users, contributors, reviewers and partners  
**Source:** https://github.com/Omoluabi1003/Omoluabi-Chess

**Scope and readiness:** A rendered chessboard prototype is not necessarily a complete rules-enforcing chess game.

Refer to the implementation and testing sections below for supported workflows. Planned capabilities are not production guarantees.

---


This repository includes a minimal 3‑D chessboard built with [Three.js](https://threejs.org/).

## Development

Serve the project directory and open `index.html` in your browser:

```bash
npx http-server .
```

Use your mouse to orbit the camera around the board.

## Testing

```bash
npm test
```
